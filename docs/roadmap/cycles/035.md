# Improvement Cycle 035

- UTC start/end: `2026-08-19T21:09:00Z` / `2026-08-19T21:40:09Z`

- Epic/story/card: E04 / E04-S03 / E04-S03-C2
- Requirement: introduce one atomic current-generation owner and a bound
  request-facing handle, then route primary inference, catalog, and context
  discovery through it. Generation and concrete request capabilities must be
  validated before runtime entry; failed replacement must retain the old
  snapshot; already admitted old work may drain. Preserve Kitsu's optional
  catalog `None` behavior and do not claim model-bound replacement or receipts.
- Evidence and expected failure: the new provider fixture initially failed
  because current/handle/successor types did not exist. After first
  implementation, full CLI acceptance found four regressions where a route
  without `models_path` raised a hard `ModelCatalog` error instead of retaining
  the existing provider-port `Ok(None)` contract. That failure established the
  distinction between optional discovery and a request-required capability.
- In scope: process-local current owner; immutable bound handles; expected and
  exact-successor replacement; profile/generation validation; stale and
  request-capability local errors; inference/catalog/context admission; ask,
  chat, scripted, foreground/subagent, compaction, slash, and resume migration;
  safe CLI/subagent classification. Out of scope: enforcing request model
  equality, production `/model` publication/rebinding, queued/background
  replacement policy, top-level management probes, receipts, or native
  Messages.
- Authority/failure/version/rollback notes: admission performs no filesystem,
  process, or network effect. Lock poisoning, stale generation, profile
  mismatch, non-successor generation, and required-capability mismatch fail
  locally without provider entry. Optional catalog absence validates staleness
  and returns `None` without a send. Errors contain no endpoint, credential,
  body, or model-controlled detail. Source revert restoring snapshot-owned raw
  runtime clones is complete rollback; no config/session/wire schema changed.
- Tests added or changed: six provider route-handle cases cover both inference
  trait paths, catalog success, optional-catalog no-send, tools/structured
  zero-send, stale inference/catalog zero-send, stale/profile/non-successor
  failed publication retention, exact successor, and admitted-old-work drain.
  CLI and subagent safe-error tests cover local route classification and secret
  exclusion.
- Implementation: `ProviderRouteCurrent<P>` owns the current immutable snapshot
  behind an `Arc<RwLock<_>>`; `ProviderRouteHandle<P>` binds one generation and
  implements the neutral `Provider` port. Admission returns an owned runtime
  only after the current-generation and request-shape checks, so replacement
  cannot retarget an admitted request. `ChatSetup` now exposes only the current
  owner, and all primary chat/catalog/context consumers bind through it.
- Review findings and fixes: review added exact profile/non-successor retention,
  stale catalog, telemetry-entry, and request-shape cases. Full acceptance then
  caught the optional-catalog semantic regression; the fix validates current
  generation first and returns `None` without entering a runtime when catalog
  capability is absent. Route-contract failures are user/configuration faults,
  not provider transport failures, and render through bounded static guidance.
