# E11 / T4-S8 — a requirement that was broken where nobody looked

- **UTC start/end:** 2026-10-15T13:00Z / 2026-10-15T15:39Z
- **Branch/base:** `features/tui_herdr_improvements` / `e0c846b`
- **Epic/story/card:** E11 / T4-S8. Records **F81**; closes **F50**.
- **Requirement:** **A8**, amended — the clause was **violated**, not merely
  untested.

- **The scope question had a real answer.** I asked whether this card was
  test-only, since **F50** had found A8 satisfied by a 50 ms poll tick and
  asserted nowhere. It is **not**: A8 was **broken at the TUI idle composer**.

  `sync_agent_counts` and `repaint_status_row` were called from **one loop
  only** — the during-a-turn typeahead. The idle read blocks with **no timeout**,
  waking only on a resize and then retrying *without a frame*. But the idle row
  **does** carry the ambient tag. **So an agent that blocked while the user sat
  at the prompt changed nothing on screen until a keystroke** — the exact failure
  R5 and the T2 blocked-agent work exist to prevent. A8's "idle prompt" latitude
  is granted to **`classic`** by its own sentence; the TUI never had it.

- **The argument against it was already in the tree.** The rationale for having
  no idle cadence says the idle prompt *"has nothing to tick"* — **true of the
  elapsed clock, false of the ambient tag** — while the reduced-motion logic
  states the opposite case in as many words: these tags stay visible *"because
  they are state and not animation: freezing them would hide a blocked agent."*
  Same reasoning, same segment, applied to reduced motion and not to idle.
  **Nobody had to discover this; it was a sentence in the file.** The lesson: **a
  justification true of one segment is not true of the row** — "nothing to tick"
  was a claim about a clock and was allowed to excuse a surface that also carries
  state.

- **The fix is a subscriber, not a poll**, and the reasoning is load-bearing.
  `read_line_inline_with_keys` is **generic over `R: Read`** and driven by
  in-memory cursors throughout the editor and composer tests, so a bounded poll
  would mean changing the signature of **the one function that owns the decoder
  and the three editor lines' byte bypass** — **F68**/**F72** territory. Because
  the counts are a **pull**, a subscriber only needs to trigger a paint: **a
  caller, not a rewrite.** Verified: **a bare wake paints nothing** — the step
  compares the projected counts against what it last showed and returns without
  painting.

- **The result that matters most, and it vindicates demanding a second test.**
  The implementer prototyped the broken shape — interval returning `Some(..)`,
  both repaints removed — and **the test author's acceptance test passed**, while
  the implementer's own behavioural test failed (`left: ""`).

  **So the acceptance test alone would have accepted an implementation that
  paints nothing** — F50's own failure mode, reproduced inside the card written
  to fix F50. It was caught only because the test author **flagged the trap in
  its own seam's doc comment** and I required a behavioural test from the
  implementer. **A test that asserts a capability *exists* is not a test that the
  capability *does anything*.** Seventh variant in this epic of *the thing we
  checked was not the thing that matters* — and the **first caught before
  shipping.**

- **A hazard found while implementing.** `repaint_status_row` **drops a paint
  inside N3's 1/60 s window without recording the key**, so a change arriving in
  that window could wait for a registry event that never comes while an agent
  sits blocked. The step therefore repaints, waits one frame interval and
  repaints again, the dedupe making the second call free when the first landed.
  **A rate limiter that silently discards rather than defers is a correctness
  problem for anything event-driven behind it.**

- **F50 closed properly.** `AMBIENT_TICK_POLL_MS` and `AMBIENT_LATENCY_BUDGET`
  put A8's numbers in the suite; raising the during-turn tick to 300 ms was tried
  and **fails by name**. F50 had proposed asserting "the poll interval constant"
  — **there was no constant**, only a bare literal, so its own cheap fix was
  unbuildable as written until this card introduced one.

- **No sleeping test.** Both the structural guard and the behavioural test avoid
  latency measurement; the only sleeps are the in-tree frame-budget helper and
  the step's own one-frame retry. With **four** open flakes, waiting out a 250 ms
  budget on a loaded machine was not worth it.
