# E11 / F126 — the published contract did not cover an event it emits

- **UTC start/end:** 2026-10-16T17:20Z / 2026-10-16T10:05Z
- **Branch/base:** `features/tui_herdr_improvements` / `ff37360`
- **Epic/story/card:** E11 / **F126**. **Retracts F121.** Corrects F126's own
  curated list. **My brief was wrong twice more on this card.**

- **The defect I shipped.** `2d1785c` added the `tool_results_dropped` JSONL event
  and never updated `docs/schemas/kitsu-chat-v1.schema.json`. I accepted that card
  and extended the same feature in the next one, checking docs both times.

- **F121 retracted.** I had recorded that the JSONL vocabulary *"is enumerated
  nowhere in the docs"*. **False** — there is a published JSON Schema, and the code
  already pins against it with `include_str!`. I had searched **prose** files and
  concluded absence; the documentation exists in a different **form**. Third time
  this session I asserted absence from a search whose shape could not find the
  thing.

- **The gap had three dimensions and two were found after my brief.** A `$defs`
  definition pinning `type` (mine); **absence from `forward_compatible_event`'s
  exclusion list** (the test author's); and **a branch of the closed root `oneOf`**
  (the implementer's). The root's keys are exactly `$schema, $id, title,
  description, oneOf, $defs` — verified — so **the two edits I prescribed alone
  would have made the schema reject a line the tool emits.** Worse than the defect.

- **The missing exclusion was the worse half of the original gap.** A missing
  definition leaves the contract *silent*; a missing exclusion makes it **actively
  mis-describe** the event — a consumer doing the right thing is told a line
  reporting **lost tool output** is an unknown event it need not understand.

- **Coverage is now enforced from the enum, not a list.** One declarative macro
  expands a single list into **both** a sample value per variant **and** an
  exhaustive `match`, so an arm and its sample cannot drift. A tenth variant
  produces `error[E0004]` — **verified by transiently adding one**, not asserted —
  and its only repair supplies a sample, which the coverage walk then requires to
  satisfy all three dimensions. **No wire name is typed anywhere in the test**;
  every one is read back out of `serde_json::to_value(&sample)["event"]`.

- **Rejected alternatives, recorded because the reasoning transfers:** a literal
  name array (*the* failure this card exists to fix), a derive that cannot handle
  non-unit variants, discriminants (not enumerable), and parsing the enum out of
  source — *"a reimplemented Rust parser is a worse oracle than the compiler."*

- **F126's own list was curated and wrong.** I wrote that eleven event types had
  defs; the enum has **nine** variants, **six** of my names were frontend events,
  and I had **omitted three real variants**. I built it from a captured stream
  rather than the enum — the exact method whose failure the finding records.
  Corrected in place.

- **One invariant added that I would not have thought of:** exactly one root branch
  pins no `type` constant. **A second catch-all would silently reopen the closed
  root and void the dimension just pinned.**

- **One surface deliberately unpinned, with its reason:** every event def having a
  branch — *"the schema author's structural choice, not an invariant the enum can
  speak to."* Declining to assert what the oracle cannot speak to is the same
  discipline as declining the `--max-rounds` assertion two cards ago.
