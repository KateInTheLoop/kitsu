# E11 / F122 — the human half, and an invariant that never named a descriptor

- **UTC start/end:** 2026-10-16T15:10Z / 2026-10-16T09:16Z
- **Branch/base:** `features/tui_herdr_improvements` / `c00b737`
- **Epic/story/card:** E11 / **F122**. Records **F125**. **N1 clarified a second
  time.** **My framing was wrong a third time on this family.**

- **What shipped.** An interactive run now prints
  `~ context budget dropped 2 tool results in round 3; the provider never saw them`
  when history trimming destroys a tool result unrecoverably — count first, one
  line per round, after `finish_line()` so it stays off the pinned status row.

- **My framing was wrong, and the author measured rather than accepted it.** I said
  to fill in the two `ToolResultsDropped` no-op arms from the previous card. Those
  are **agent-telemetry / agent-timeline** surfaces, and **a plain interactive chat
  has no agent view** — proved by enumerating the **complete 23-line human channel**
  of a styled PTY run and showing nothing in it comes from either arm. The human
  channel is the **runtime-notice sink** (`eprintln!("~ {notice}")` after
  `finish_line()`), which recognised exactly **two** event variants before this card.
  **Both arms are left as no-ops.**

- **The gate was the card's real content.** That sink is **not TTY-gated**: it fires
  on any non-`--jsonl` run, piped included — measured, a piped run's stderr is
  **six lines, not empty**. So an ungated arm prints on N1's non-TTY and `--plain`
  surfaces, and the mutation proves it: **three** N1 guards fail. Shipped gate is
  `stderr_styled() && is_tty()`, wired as a **preceding** arm in all three sinks so
  `format_runtime_notice` is never reached for this event and stays bit-for-bit
  unchanged.

- **F125 — N1 never said which file descriptor, and three composites answered
  differently.** `is_tty()` is stdout; `stderr_is_tty()` is separate; N1's own
  parenthetical says stdout; and **the three inline composites in the binary all key
  on stdin**, none with a `jsonl` term. They differ for `kitsu chat <prompt> | tee`.
  **Resolved per-descriptor**: when a descriptor is not a terminal, *its* bytes stay
  identical — never one global condition, which is why no single predicate could
  express it. **And so "extract the shared predicate" was the wrong instinct**: the
  author measured four distinct conditions for four distinct jobs, recommended
  against extraction, and left them.

- **One line per round, decided by measurement.** A two-call fixture showed **two
  results destroyed in one round produce exactly ONE event with `dropped: 2`** —
  `trim_tool_results_counted` aggregates within a round. Two lines would overstate
  how many times context was lost.

- **A new harness was needed, and why is worth keeping.** Neither existing PTY
  harness could observe this: one **hardcodes `--plain`** (so it cannot see anything
  gated on styling) and the other points at an invalid gateway and only submits
  slash commands (so it cannot drive a tool turn). The new one drives the real REPL
  **on transcript triggers, never on a sleep**.

- **Honest pin strengths, stated by the author rather than glossed.** Non-TTY is a
  **true byte pin** against all six of today's stderr lines. JSONL pins the full
  13-element ordered `"type"` sequence plus empty stderr. `--plain` and
  `--screen-reader` are driven **on a real PTY** (a `--plain` pipe is just the
  non-TTY surface again) and, because a redraw stream cannot be byte-pinned
  honestly, assert silence over an **enumerated vocabulary** — `dropped`, `elided`,
  `discarded`, `lost` — so a synonym nobody predicted cannot pass as silence.

- **Thresholds do not transfer between carriers.** The previous card's lossless pair
  **trips the context preflight** on the interactive carrier, whose protected prompt
  is larger, and never reaches the trimmer. The author swept and re-measured on this
  carrier, fencing each number with a provider-side assertion so drift fails loudly
  instead of turning a silence into a tautology.
