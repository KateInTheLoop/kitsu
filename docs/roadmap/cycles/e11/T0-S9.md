# E11 / T0-S9 — the inline hint slot

- **UTC start/end:** 2026-10-14T01:28Z / 2026-10-14T02:25Z
- **Branch/base:** `features/tui_herdr_improvements` / `be95229`
- **Epic/story/card:** E11 / T0-S9
- **Requirement:** **R4**, partially — see the status note now attached to R4 in

- **What shipped.** The inline viewport's pinned row gained the **hint slot**
  the classic during-turn row already had: the reverse-search status while
  Ctrl+R is active, and otherwise the inline slash-completion suffix (typing
  `/s` hints `teer`). The two compete for columns exactly as in the classic
  row — the search status is *reserved* and claims its columns before the draft
  is windowed, so it survives a long draft, while the completion suffix is
  unreserved and drops when the row is narrow.

- **A scoping correction I had to make twice, recorded because it is the
  substance of this card.** T0-S8 said Tab completion, the palette and the
  search status shared one cause and one fix. **That was wrong**, and I caught it
  while scoping this card by reading what `typeahead_slash_hint` actually
  returns: `"teer"` for `"/s"` — a one-line ghost suffix, not a bordered
  palette. So the slot carries two things, this card restores those two, and the
  rest is separate work. Corrected in `README.md`, `CHANGELOG.md`,
  `docs/ux-design.md`, the T0-S6 go/no-go record, F20 and a production doc
  comment. The lesson is in F20: *"these share a cause" is a claim about code,
  and I made it twice from reading a summary rather than the call sites.*

- **The anti-drift decision, which is the real engineering content.** The
  classic row's composition is not trivial — it reserves the hint's columns,
  windows an over-wide draft around the cursor with an ellipsis, and drops the
  spinner segment first on a narrow terminal. Reimplementing that for the inline
  row would guarantee the two renderers drift, which is a bug class this project
  keeps finding. So I authorised an exception to the usual rule that
  `kitsu-render` is off limits, on two conditions: the classic row must not
  change, and a real refactor would mean stopping to re-card.

  Neither was needed. Sharing cost **two two-line wrappers**:
  `compose_input_row(draft, cols)` is literally `compose_row(None, Some(draft),
  0, 0, 0, cols)`, and `terminal_columns()` exposes the existing width probe so
  the bridge never re-probes. `compose_row` itself is untouched. The pinning
  test asserts `compose_input_row(..) == compose_row(..)` over four cases —
  **equality against the classic row rather than a literal**, so any future
  change that makes the inline row differ breaks the test rather than shipping
  a divergence.

- **A latent bug the test author found that no test could force.** The reader
  repainted only when the editor reported `changed`. Entering and leaving search
  *happens* to set that flag — so the reserved hint did repaint, but as the
  author put it, "that is the editor's goodwill, not a contract". If a future
  editor change stopped setting it on a search transition, the hint would go
  silently stale and nothing would catch it. **Fixed by making it contractual:**
  the reader now tracks the last painted `(hint, reserved)` pair and repaints
  when it differs, in addition to `changed`. The hint on the row is a function
  of editor state, not of which transitions the editor chooses to flag.

- **Review findings and fixes:**
  1. The test author rejected a tempting contract — passing `&LiveDraft` through
     the paint seam, which would make drift structurally impossible — for a
     stated reason: the reader does not know the prompt, so it would have to
     hand out a half-filled value for the guard to complete. Four documented
     positional arguments mirroring `live_input_update` is the better contract,
     and the guard still builds a real `LiveDraft` internally, which is where
     the two renderers converge on one value type. Accepted.
  2. Accepted an implementer judgement not pinned by any test: the row falls back
     to the status only when draft **and** hint are both empty. Ctrl+R with no
     query yet gives an empty draft and a reserved status, and the narrower
     condition would have swallowed it.
  3. The test author deliberately left the release profile to the implementer
     rather than spend minutes on code about to be replaced — reasonable, and
     the implementer ran both.
