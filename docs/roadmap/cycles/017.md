- Requirement: expose the same validated run identity, neutral semantic class,
  and assistant disposition in every terminal human model-command receipt;
  preserve redirected parseability and compact TTY presentation without making
  the renderer or process exit code canonical.
- Evidence and expected failure: core label tests first failed because neutral
  classes/dispositions had no canonical projection labels; renderer tests
  failed because no human outcome DTO or receipt argument existed. Existing
  timing JSON contained only duration/status and sequential human processes had
  no observable identity.
- In scope: canonical neutral labels; typed CLI error classification independent
  from exit code; last assistant disposition; a renderer-only projection DTO;
  additive redirected/TTY receipt fields; human success/provider/tool/policy
  parity and sequential-ID tests. Out of scope: terminal phase ownership,
  persistence/delivery classification, JSONL schema additions, session changes,
  or a second host.
- Authority/failure/version/rollback notes: no authority, provider request, or
  tool behavior changes. Existing exit codes and `kitsu-timing:` prefix remain;
  redirected JSON gains additive fields. Policy and tool failures retain exit 1
  but now share the already-established neutral `tool_fault` class. Rollback
  restores the duration/status-only human receipt.
- Tests added or changed: four core run-contract tests freeze every neutral
  label; renderer vectors cover success/partial/provider/cancel/interruption;
  CLI verifies safe distinct sequential human IDs, committed success,
  provider-fault discard, and human/JSONL tool-policy parity.
- Implementation: `TerminalOutcome` labels remain standard-library-only in
  `kitsu-core`. `CliError` carries a neutral class separately from its exit
  code; assistant terminal transitions update a bounded atomic disposition.
  Main constructs the terminal from its process `RunSpec` and passes only
  `{run_id,outcome,assistant}` to `kitsu-render`, which sanitizes TTY fields and
  serializes redirected JSON safely.
