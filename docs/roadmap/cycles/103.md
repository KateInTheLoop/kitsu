- Epic/story/card: E06 / E06-S03 / E06-S03-C1
- Requirement: the restricted MCP experiment needs a bounded, revision-pinned,
  tools-only wire state machine that cannot silently accept ambient protocol
  capabilities, concurrent requests, malformed frames, or ambiguous IDs.
- Evidence and expected failure: Kitsu had no MCP framing or state machine. The
  new fixtures initially had no decoder, encoder, request identity, lifecycle
  state, capability admission, or list/call envelope parser to exercise.
- In scope: compact newline JSON encoding, fail-stop bounded decoding, exact
  initialize/initialized handshake, tools/list and tools/call envelopes, one
  total request in flight, strict positive integer response correlation, and
  typed remote/protocol faults. Out of scope: process/transport ownership,
  deadlines, cancellation, inventory validation/publication, tool namespacing,
  configuration, credentials, receipts, and product routing.
- Authority/failure/version/rollback notes: MCP revision `2025-11-25` is a
  compiled constant. The client advertises `{}` capabilities, requires server
  `tools`, rejects all non-tools capabilities, rejects `listChanged=true`, and
  never services server requests or notifications. Framing failure poisons the
  decoder. Revert removes an uncomposed pure module with no stored state.
- Tests added or changed: 13 provider-free unit fixtures cover fragmented and
  multi-frame CRLF input; oversize poisoning; malformed, empty, and truncated
  input; exact encoding bounds; pinned zero-capability initialization; state
  ordering; one in-flight request; future revisions and ambient capabilities;
  changing inventory; string/mismatched/duplicate/late IDs; server methods;
  exact list/call vocabulary; remote errors; and malformed matching responses.
  The complete combined `kitsu-tools` suite passes all 246 tests.
- Implementation: `LineDecoder` and `encode_line` own only bounded frames.
  `ToolsOnlyClient` owns lifecycle state, monotonic positive IDs, and at most one
  pending kind. Valid list/call results remain raw values after minimum envelope
  checks so the next inventory card can validate and publish them atomically.
- Review findings and fixes: integration review preserved the deliberately
  narrow compatibility contract: string IDs and list-change notifications are
  unsupported, the client never negotiates unrelated capabilities, and adding
  a later incompatible MCP revision requires another compiled codec rather
  than widening this one. The codec remains independent from both the prepared
  child seam and request inventory.
- Acceptance commands/results: all 246 combined `kitsu-tools` tests and strict
  all-target crate Clippy pass; rustfmt and cached diff checks pass. The full
  workspace suite, strict workspace Clippy, roadmap and boundary checks, stale-
  claim scan, and original-worktree hygiene run before this commit.
