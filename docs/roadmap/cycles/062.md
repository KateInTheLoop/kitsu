- Requirement: compose the accepted logical and physical seams into one
  provider-free whole-operation transaction. It must validate and encode before
  effects, reject already-stale work before candidate allocation, retain the
  exact session fence through immutable install and repeated HEAD admission,
  and report old/new publication plus orphan durability without claiming
  rollback after an installed cut.
- Evidence and expected failure: six isolated transaction fixtures were added
  first; the focused target failed to compile because no composition owner,
  candidate-residue vocabulary, or private canonical/physical sibling seam
  existed.
- In scope: deterministic canonical encoding; store/session/revision/parent/
  selected-HEAD binding; preconstructed neutral receipts; exact session writer
  fence; expected-revision pre-admission; immutable candidate install; physical
  CAS recheck; confirmed versus unconfirmed unselected candidates; exact versus
  conflicting same-revision collisions; confirmed and published-unconfirmed
  success. Out of scope: current-v1 migration or writes, production operation
  assembly/mounting, candidate reclamation/resume, artifacts beyond their
  logical manifest, recovery, branch-at-turn, second adapter, and X005.
- Authority/failure/version/rollback notes: the transaction accepts only the
  closed canonical value and stores its deterministic encoding; it accepts no
  provider, tool registry, credential, grant, path selector, or presentation
  object. Receipt construction and identity checks occur before the fence or
  physical effects. A stale expected revision is zero-allocation. A candidate
  cut is explicitly installed-unselected, and a completed HEAD install is
  published even when durability confirmation fails. Current v1 remains the
  production rollback because this module has no caller.
- Tests added or changed:

    confirmed neutral receipts;
  - stale A-versus-B conflict allocates no stale revision candidate and keeps B;

  - retrying an orphan distinguishes exact preserved bytes from a conflicting
    same-revision collision and never overwrites the first candidate.
