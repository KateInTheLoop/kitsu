- Requirement: copy one branch-referenced immutable artifact only after its
  source manifest and content verify completely; preserve schema, artifact ID,
  media type, and exact bytes while rewriting the session identity into a
  distinct destination; publish with atomic no-overwrite behavior; and leave
  no destination record for a missing/tampered source or failed admission.
- Evidence and expected failure: the requirements-first fixture failed to
  compile because `PhysicalFileStoreV1::copy_artifact_no_overwrite` did not
  exist.
- In scope: one verified immutable source read, distinct source/destination
  admission, destination-scoped identity rewrite, reuse of the existing
  descriptor-pinned create-only installer, collision preservation, and exact
  reopened-content/metadata verification. Out of scope: copying an artifact
  set, rollback of earlier copies, source/destination writer-fence composition,
  branch candidate/HEAD publication, receipts/cuts, CLI selectors, production
  mounting, authority acquisition, export/import, second stores, and X005.
- Authority/failure/version/rollback notes: artifact records contain no grants,
  approvals, credentials, or leases. The source is opened and digest-verified
  before destination namespace creation. The destination manifest is rebuilt
  under the same artifact schema but its own session identity. Existing
  destination records are never replaced. Physical schema and current-v1
  production bytes are unchanged; removing the private unmounted helper is the
  complete rollback.
- Tests added or changed:

  - source content tampering fails verification before any destination record
    appears.
- Implementation: reject an equal destination identity, open the source through
  the existing closed descriptor-pinned verifier, then call the existing atomic
  no-overwrite installer with verified owned bytes and metadata plus the fresh
  destination session. No unverified manifest field or apparent path is copied.
