
# Kitsu System Design

Kitsu is a multi-agent developer CLI focused on local AI models and structured orchestration.

Key goals:
- Local-first AI development
- Multi-agent collaboration
- Structured terminal UX
- Reproducible automation

Core components:
- CLI interface
- UI renderer
- Agent Deck orchestrator
- Providers
- Tools

Agent Deck manages concurrent agents and supports detach/attach workflows similar to tmux.
