## Selected improvement

The reserved finalization guard is now a host-owned
`AgentError::ToolCallDuringToolFreeFinalization`, not a provider-controlled
`InvalidResponse` detail. Human output states exactly:

> model returned a tool call after tools were withheld for structured
> finalization; no tool was executed

JSONL keeps the compatible provider classification, exit `2`, and
`provider_failures: 1`, while adding the optional safe cause
`tool_call_during_tool_free_finalization`. Because the cause comes from a
closed local variant, it cannot copy provider response text, URLs, or secrets.
Subagent classification remains a sanitized provider-invalid-response class.
