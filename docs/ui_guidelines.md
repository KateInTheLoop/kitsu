
# Kitsu UI Guidelines

Kitsu aims to deliver a delightful but disciplined terminal UX.

Principles:
- Cute but professional
- Structured progress visibility
- Minimal noise

Rules:
- Respect --plain and NO_COLOR
- Disable animation in non-TTY
- Never spam emojis

Core symbols:
🦊 identity
⛩ milestone
✨ thinking

UI Layout:
Header
Progress pipeline
Main output
Tool receipts
Summary
